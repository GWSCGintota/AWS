# AWS Storage and Database Services
#### Storage Services


| Service Type | AWS Service | Description |
|---|---|---|
| [Object Storage](storage_services/object_storage%28s3%29/s3.md) | Amazon S3 | Highly scalable object storage for any type of data. |
| Block Storage | Amazon EBS | High-performance block storage for EC2 instances. |
| File Storage | Amazon EFS / Amazon FSx | Managed file storage for shared access. |
| Archive Storage | Amazon S3 Glacier | Low-cost archive storage for long-term data retention. |
| Hybrid Storage | AWS Storage Gateway | Connects on-premises storage systems with AWS cloud storage. |




#### Database Services


| Service Type                | AWS Service | Description |
|-----------------------------|---|---|
| Relational Databases (SQL)  | Amazon RDS, Amazon Aurora, MySQL, PostgreSQL, SQL Server | Managed relational database services for structured data. |
| NoSQL Databases             | Amazon DynamoDB | Fast and flexible NoSQL database service designed for applications at any scale. |
| Data Warehouse              | Amazon Redshift | Petabyte-scale cloud data warehouse for analytics and reporting. |
| In-Memory Databases         | Amazon ElastiCache, Amazon MemoryDB | High-performance in-memory data stores for low-latency applications. |
| Graph Database              | Amazon Neptune | Managed graph database service for highly connected data. |
| Time-Series Database        | Amazon Timestream | Managed time-series database for IoT and operational applications. |
